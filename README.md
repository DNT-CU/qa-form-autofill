## Autofill QA – Chrome Extension

This little side project was born after spending hours manually testing forms at work.  
I decided to automate the process with a simple Chrome extension that can automatically fill almost any form with ~~jojos~~ dummy data.

It was an awesome opportunity to experiment with AI-assisted coding and learn the basics of JavaScript.

**Known bug:** Sometimes the extension doesn’t work properly on phone number inputs that don’t use the `type="tel"` attribute.
